# Trame — Politique de confidentialité

*Dernière mise à jour : 13 novembre 2026*

Trame est une application pour écrire et mettre en page des livres. Elle est éditée par Baptiste Shizeh.

## En bref

**Trame ne collecte aucune donnée personnelle.** Vos livres restent sur votre ordinateur.

## Vos livres

Vos livres, votre carnet (personnages, lieux, pense-bête) et vos réglages sont enregistrés uniquement sur votre ordinateur, dans le dossier de données de Trame. Ils ne sont envoyés nulle part. Les PDF et copies que vous exportez sont écrits à l'endroit que vous choisissez.

## Ce que Trame n'a pas

- Pas de compte à créer.
- Pas de statistiques d'utilisation, pas de mesure d'audience, pas de publicité.
- Pas de partage de données avec qui que ce soit.

## Connexions à Internet

Trame fonctionne sans Internet. Elle se connecte seulement dans ces cas :

- **Mises à jour** (version téléchargée hors Microsoft Store) : au lancement, Trame vérifie sur GitHub si une nouvelle version existe. Seule la demande de vérification est envoyée, comme pour la consultation d'une page web. Les versions installées depuis le Microsoft Store sont mises à jour par le Store.
- **Statut Discord** (facultatif, désactivable dans le menu du livre) : si Discord est ouvert sur votre ordinateur, Trame peut afficher « Écrit un roman » et un nombre de mots dans votre statut. Le titre du livre n'est jamais montré, sauf si vous l'activez. Cet échange se fait localement avec l'application Discord.
- **Dictée vocale** : le bouton micro ouvre la dictée de Windows. Elle est fournie par Microsoft et soumise à ses propres règles de confidentialité.
- **Liens** (aide, signaler un problème) : ils s'ouvrent dans votre navigateur.

## Enfants

Trame ne collecte aucune donnée, y compris celles des enfants.

Install Trame on Windows

Two minutes, just once. After that, Trame updates itself.

Download for Windows

  1. Download Trame

    Click “Download for Windows” . The file lands in your Downloads folder. Trame runs on Windows 10 and 11.

  2. Open it

    Double-click the downloaded file. If Windows says “Windows protected your PC”, click More info, then Run anyway.

  3. You’re all set

    Trame installs and opens. New versions then install in one click.

On Windows, prefer the Microsoft Store? Trame is there too, with no warning at install. The Store gets the major versions; the direct download gets every new feature as soon as it’s out.

Why this warning?

Windows shows this message for apps from small independent publishers who don’t pay for a certificate. Trame is free and safe: it collects no data, and your books stay on your computer.

Installer Trame sur Windows

Deux minutes, une seule fois. Ensuite, Trame se met à jour tout seul.

Télécharger pour Windows

  1. Téléchargez Trame

    Cliquez sur « Télécharger pour Windows » . Le fichier arrive dans votre dossier Téléchargements. Trame fonctionne sur Windows 10 et 11.

  2. Ouvrez-le

    Double-cliquez sur le fichier téléchargé. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires, puis sur Exécuter quand même.

  3. C’est prêt

    Trame s’installe et s’ouvre. Les nouvelles versions s’installent ensuite en un clic.

Sur Windows, vous préférez le Microsoft Store ? Trame y est aussi, sans message d’avertissement à l’installation. Le Store reçoit les grandes versions ; le téléchargement direct reçoit toutes les nouveautés dès leur sortie.

Pourquoi cet avertissement ?

Windows affiche ce message pour les applications de petits éditeurs indépendants qui ne paient pas de certificat. Trame est gratuite et sans danger : elle ne collecte aucune donnée, et vos livres restent sur votre ordinateur.

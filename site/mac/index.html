Installer Trame sur Mac

Cinq minutes, une seule fois. Ensuite, Trame se met à jour tout seul.

Télécharger pour Mac

  1. Téléchargez Trame

    Cliquez sur « Télécharger pour Mac ». Le fichier Trame.dmg arrive dans votre dossier Téléchargements. Trame fonctionne sur tous les Mac récents et anciens (Apple Silicon et Intel), avec macOS 11 ou plus récent.

  2. Glissez Trame dans Applications

    Ouvrez Trame.dmg. Une fenêtre s’affiche : attrapez l’icône Trame et lâchez-la sur le dossier Applications, en suivant la flèche.

  3. Ouvrez Trame

    Ouvrez le dossier Applications et double-cliquez sur Trame (ou appuyez sur ⌘ + Espace et tapez « Trame »). La première fois, le Mac affiche que Trame n’a pas pu être vérifié : cliquez sur Terminé, surtout pas sur « Placer dans la corbeille ».

  4. Autorisez Trame, une seule fois

    Ouvrez Réglages Système > Confidentialité et sécurité, descendez jusqu’à la ligne sur Trame et cliquez sur Ouvrir quand même. Confirmez avec le mot de passe de votre Mac. Vous n’aurez plus à le faire.

  5. C’est prêt

    Pour garder Trame sous la main, faites-le glisser depuis Applications vers le Dock. Les nouvelles versions s’installent ensuite en un clic.

Vous avez ouvert Trame sans le ranger ?

Pas de souci : Trame vous propose « Installer dans Applications ». Acceptez, il s’y range tout seul et se relance.

Pourquoi cet avertissement ?

Apple affiche ce message pour les applications qui ne sont pas enregistrées auprès d’elle, un service payant. Trame est gratuite et indépendante : elle ne contient rien de dangereux et ne collecte aucune donnée. Vos livres restent sur votre Mac.
